# PIS Scanner

PIS Scanner — сканер Minecraft Java-серверов с интерфейсом в терминале и Telegram-ботом. Написан на Rust. Найденные серверы сохраняются в локальную базу SQLite.

## Что умеет

- Искать серверы в нескольких режимах, в том числе по заданным подсетям, доменам, никам, Playit и Ngrok.
- Показывать информацию о серверах, сохранять результаты и искать их в базе.
- Отправлять результаты через Telegram-бота. В боте есть фильтры, подписки, промокоды и управление пользователями.
- Работать через SOCKS5-прокси. В настройках доступны глубокая проверка портов и RCON.

Используйте проверки только для серверов, которые принадлежат вам или на проверку которых у вас есть разрешение.

## Установка и запуск

Нужны [Rust и Cargo](https://www.rust-lang.org/tools/install). В Windows также могут понадобиться инструменты сборки Microsoft C++.

Откройте терминал в папке проекта и выполните:

```bash
cargo run --release
```

Для сборки без запуска:

```bash
cargo build --release
```

Готовый файл появится в `target/release/`. В Windows он называется `dank_scanner.exe`. Программу лучше запускать из папки проекта, чтобы она нашла изображения для бота.

## Управление

- `1`–`7` или `Tab` — переключение вкладок.
- `Space` — запуск и остановка сканирования.
- `m` — режим поиска; `b` — выбор базы подсетей.
- `+` и `-` — число потоков.
- `k` во вкладке бота — ввод токена Telegram.
- `q` — выход.

Остальные клавиши указаны во вкладке справки.

## Настройка

Токен Telegram-бота можно ввести в программе или записать в файл `tg_config.txt` в папке запуска. Программа также может сохранить его в базе `servers.db` и рядом с исполняемым файлом. Не выкладывайте эти файлы в открытый доступ.

Результаты и настройки хранятся в `servers.db`. Для целевых подсетей используются файлы `targeted_lic.txt` и `targeted_nolic.txt`, для прокси — `proxies.txt`. Изображения меню бота лежат в папке `2/`.

В проекте есть интеграция DonatePay. Для неё нужен собственный токен в `donatepay_api.txt`; перед использованием платежей проверьте настройки и работу обработки транзакций.
