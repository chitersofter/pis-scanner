# PIS Scanner

Терминальное приложение на Rust для обнаружения и мониторинга Minecraft Java-серверов. Проект объединяет сетевой сканер, локальную базу SQLite и Telegram-бота с управлением пользователями и подписками. Интерфейс и значительная часть сообщений — на русском языке.

> Используйте сетевые проверки и функции подключения только для систем, которые принадлежат вам или на проверку которых у вас есть разрешение. Некоторые режимы генерируют адреса автоматически, а глубокая проверка и RCON могут создавать значительную нагрузку и взаимодействовать с сервером.

## Возможности

- Терминальный интерфейс на Ratatui: результаты, статистика, настройки, база, управление ботом и пользователями.
- Несколько режимов поиска: обычный и целевой поиск, комбинированный режим, поиск по нику, Playit, Ngrok и варианты имён DNS.
- Получение информации о Minecraft Java-сервере и сохранение результатов в SQLite; фильтрация, поиск и экспорт через бота.
- Настройка числа потоков, лимита проверок, версии и фильтров; необязательная глубокая проверка портов и работа через SOCKS5.
- Telegram-бот с уведомлениями, профилями, подписками, промокодами, балансом и интерфейсом администратора; интеграция DonatePay присутствует в исходниках.

Это исходная экспериментальная версия, а не проверенный промышленный сервис: сетевые режимы, платёжные сценарии, права администратора и доступность внешних сервисов требуют самостоятельной проверки перед использованием. Результаты проверок не являются доказательством уязвимости.

## Требования

- Rust и Cargo с поддержкой edition 2021: [установка Rust](https://www.rust-lang.org/tools/install).
- Терминал с поддержкой ANSI и достаточным размером окна.
- Для Windows может потребоваться набор инструментов сборки Microsoft C++ (MSVC).
- Подключение к сети для загрузки зависимостей и работы сетевых функций.

## Сборка и запуск

В корне проекта:

```bash
cargo build --release
cargo run --release
```

Готовый исполняемый файл находится в `target/release/` (`dank_scanner.exe` в Windows). Запускайте программу из корня проекта: относительные пути к изображениям, настройкам и базе зависят от текущего рабочего каталога. Для остановки используйте `q`. Полный список клавиш находится во вкладке справки приложения.

## Управление

- `1`–`7`, `Tab` и `Shift+Tab` — вкладки; `q` — выход.
- На вкладке сканера: `Space` — запуск или остановка, `m` — выбор режима, `b` — выбор целевой базы, `+` / `-` — изменение числа потоков.
- `i` — лимит проверок, `v` — версия Minecraft, `n` — ник, `d` — домен. `p` переключает глубокую проверку, `r` — автоматическую команду RCON.
- Во вкладке бота `k` редактирует токен, `t` приостанавливает или возобновляет работу бота. Другие сочетания показаны в самой программе.

## Данные и конфигурация

Приложение создаёт `servers.db` в рабочем каталоге и сохраняет там результаты и настройки. Файлы `targeted_lic.txt` и `targeted_nolic.txt` используются для целевых подсетей и могут пополняться при работе. `proxies.txt` — необязательный список SOCKS5-прокси. Рабочие базы, списки и секреты исключены из публичной копии и через `.gitignore`.

Для Telegram укажите токен бота через интерфейс или локальный `tg_config.txt`. Программа может сохранять его в SQLite и рядом с исполняемым файлом: защищайте эти файлы и не публикуйте их. По умолчанию запросы идут на `https://api.telegram.org`; необязательный `tg_api.txt` переопределяет адрес API. Сторонний посредник сможет увидеть токен и содержимое запросов, поэтому используйте только доверенный адрес. Каталог `2/` содержит изображения меню бота.

Для DonatePay код читает токен из локального `donatepay_api.txt` либо из конфигурации в базе. В публичной копии встроенные токен и идентификатор получателя удалены. Настройка и платёжный поток требуют отдельной проверки: не используйте реальные платежи до проверки корректности конфигурации, прав и обработки транзакций.

## Устройство проекта

- `src/main.rs`, `src/ui.rs` — состояние приложения, обработка клавиш и терминальный интерфейс.
- `src/scanner.rs`, `src/minecraft.rs` — запуск проверок и взаимодействие с Minecraft Java.
- `src/playit.rs`, `src/ngrok.rs`, `src/proxy.rs`, `src/utils.rs` — вспомогательные сетевые режимы и функции.
- `src/db.rs` — SQLite; `src/telegram.rs` — бот; `src/donatepay.rs` — интеграция DonatePay.
- `2/` — изображения для меню Telegram.
